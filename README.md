Hi, welcome to swiftcard!

With over a week dedicated to development, I engineered Swift
Cart, an e-commerce platform leveraging the MERN stack, Vite,
JWT authentication, Redux Toolkit for ReactJS optimization,
and employing CRUD principles throughout. Noteworthy features
include an intuitive admin interface facilitating seamless
product management, comprehensive oversight of user payments,
and the ability to modify user profiles and administrative
privileges. Furthermore, users benefit from a streamlined
order tracking system, while administrators efficiently
monitor payment statuses and manage delivery process.
